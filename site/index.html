What You Get

  • Use a focus timer with optional auto-blocking mode.
  • Track weekly focus efficiency and consistency.

Install in 60 Seconds

  1. Download the latest zip and extract it on your computer.
  2. Open chrome://extensions (or edge://extensions).
  3. Enable Developer mode.
  4. Click Load unpacked and select the extracted project folder.
  5. Pin IntentionalTube and start YouTube with fewer distractions.
